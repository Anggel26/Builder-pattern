# Builder Pattern

Implementation of the Builder design pattern in Java for a role-playing game character creator.

## Structure

The code is separated into packages reflecting the classic roles of the pattern:
- **rpg.product**: The complex object (`Character`).
- **rpg.builder**: The interface and logic for step-by-step construction (`CharacterBuilder`).
- **rpg.director**: Predefined templates and combinations (`CharacterDirector`).
- **rpg.client**: The consumer of the builder (`Main`).
